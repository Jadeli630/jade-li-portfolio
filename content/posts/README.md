# Adding a post

Create a new Markdown file in this folder. Use this frontmatter at the top:

```md
---
Title: A clear post title
Slug: a-clear-post-title
Summary: One restrained sentence for cards and previews.
Section: Tech
Content Type: Case
Capability Tags: [Systems Thinking, Product Sense, Digital Solution Design]
Featured on Home: Yes
Publish Date: 2026-08-21
---

Write the post here.

## Optional subheading

- Bullets are supported.
```

Allowed sections are `Tech`, `Commercial`, `Cultures`, and `Fieldnotes`.
Allowed content types are `Case`, `Research`, `Essay`, and `Fieldnote`.
`Featured on Home` accepts `Yes` or `No`.
